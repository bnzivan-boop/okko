# Logos

One file per listing, named after the listing id:

    assets/logos/petit-paradis.png
    assets/logos/like-bricks.png
    assets/logos/tg-mena.png
    assets/logos/ags-foods.png

## Rules

- PNG or SVG with a transparent background (jpg and webp also load, but a white
  box will show around the mark).
- It must fit a rectangle: aspect ratio between 1:1 and 4:1.
- Minimum 400 × 400 px for a square mark, 1200 × 400 px for a horizontal one.
- Up to 2 MB.
- The logo is scaled to fit the frame (`object-fit: contain`) — never cropped,
  so keep a little padding inside the file itself.

Where it shows: the tile on the catalog card cover, the header of the deal page
and the rows in the seller console. Until a file is uploaded the slot shows a
monogram, so the layout stays the same.

## OKKO CAP brand logo

    assets/logos/okko-cap.svg     ← header and footer of the site

- SVG preferred (png / webp also work).
- Use a **light version**: it sits on the dark header and the dark footer.
- Horizontal lockup, transparent background. It is scaled to 26 px height in the
  header and 30 px in the footer, so keep the file at least 300 px wide.
- Until the file is there, the drawn mark + "OKKO CAP" wordmark is used.
